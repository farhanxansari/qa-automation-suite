# BUG-006: Non-admin user can list all registered users

| Field | Value |
|---|---|
| Module | Access Control API |
| Severity | High |
| Priority | P0 |
| Environment | OWASP Juice Shop v20.2.0 (localhost:3000), Chromium |
| Status | Open |

## Steps to reproduce
1. Log in as a normal customer
2. GET /api/Users with the Bearer token

## Expected
403 Forbidden (admin only)

## Actual
200 OK with every user's email and role (user enumeration / PII exposure)

## Root-cause hypothesis
The route checks only that the user is authenticated. It never checks the admin role.
