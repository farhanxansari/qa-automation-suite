# BUG-002: Reflected DOM XSS via search query parameter

| Field | Value |
|---|---|
| Module | Search (UI) |
| Severity | High |
| Priority | P0 |
| Environment | OWASP Juice Shop v20.2.0 (localhost:3000), Chromium |
| Status | Open |

## Steps to reproduce
1. Open /#/search?q=<iframe src="javascript:alert(`xss`)">

## Expected
Search term is rendered as plain text

## Actual
The iframe is injected into the DOM and alert('xss') runs

## Root-cause hypothesis
The search term is bound to the page as HTML (Angular sanitizer bypassed with bypassSecurityTrustHtml) instead of being interpolated as text.
