# BUG-001: SQL injection in login email field bypasses authentication

| Field | Value |
|---|---|
| Module | Login / Auth API |
| Severity | Critical |
| Priority | P0 |
| Environment | OWASP Juice Shop v20.2.0 (localhost:3000), Chromium |
| Status | Open |

## Steps to reproduce
1. POST /rest/user/login with body {"email": "' OR 1=1--", "password": "x"}
2. (UI) Enter `' OR 1=1--` as email, any password, click Log in

## Expected
401 Unauthorized, "Invalid email or password."

## Actual
200 OK with a valid JWT. User is logged in as the first account in the DB (admin).

## Root-cause hypothesis
The email value is concatenated into a raw SQL string. It should be passed as a bound parameter (ORM / prepared statement).
