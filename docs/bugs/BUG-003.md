# BUG-003: Registration accepts malformed email addresses

| Field | Value |
|---|---|
| Module | Registration API |
| Severity | Low |
| Priority | P2 |
| Environment | OWASP Juice Shop v20.2.0 (localhost:3000), Chromium |
| Status | Open |

## Steps to reproduce
1. POST /api/Users/ with email "not-an-email-abc123" plus valid password fields

## Expected
400 Bad Request with validation message

## Actual
201 Created; account exists with an unusable email

## Root-cause hypothesis
No server-side email format validation. Only the frontend form checks the format.
