# BUG-005: IDOR: any logged-in user can read another user's basket

| Field | Value |
|---|---|
| Module | Access Control API |
| Severity | High |
| Priority | P0 |
| Environment | OWASP Juice Shop v20.2.0 (localhost:3000), Chromium |
| Status | Open |

## Steps to reproduce
1. Register user A and user B, note B's basket id (bid)
2. As A: GET /rest/basket/{B's bid}

## Expected
403 Forbidden

## Actual
200 OK with B's basket contents

## Root-cause hypothesis
The basket is looked up by its id from the URL, without checking that it belongs to the user in the JWT.
