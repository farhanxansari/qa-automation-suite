# BUG-004: Basket item quantity accepts zero and negative values

| Field | Value |
|---|---|
| Module | Basket API |
| Severity | High |
| Priority | P1 |
| Environment | OWASP Juice Shop v20.2.0 (localhost:3000), Chromium |
| Status | Open |

## Steps to reproduce
1. Log in, add product to basket
2. PUT /api/BasketItems/{id} with {"quantity": -1}

## Expected
400 Bad Request (quantity must be >= 1)

## Actual
200 OK; basket total goes negative, which allows a negative-value order (money refunded to the attacker)

## Root-cause hypothesis
The PUT handler is missing a lower-bound validation.

`tests/api/test_products_basket_api.py::test_TC_API_BASKET_02_quantity_boundary_rejected[0,-1]` (marked `xfail(strict=True)`; remove the marker when fixed)
