# BUG-008: Content-Security-Policy header missing

| Field | Value |
|---|---|
| Module | Security headers |
| Severity | Medium |
| Priority | P1 |
| Environment | OWASP Juice Shop (localhost:3000), Chromium |
| Status | Open |

## Steps to reproduce
1. Send GET http://localhost:3000/
2. Inspect the response headers (DevTools → Network → first request → Response Headers)

## Expected
A `Content-Security-Policy` header restricting script sources (e.g. `script-src 'self'`).

## Actual
Header is absent. Response only includes X-Content-Type-Options, X-Frame-Options and Feature-Policy.

## Impact
No browser-side defence against injected scripts. A CSP would have blocked the payload in BUG-002 (DOM XSS).

## Root-cause hypothesis
No CSP middleware configured (e.g. helmet's `contentSecurityPolicy`).
